# Job: 9:16 vertical clips

Produce a 9:16 (1080×1920) portrait clip for socials: a time range of the
source, cropped to a horizontal slice, rendered as a **new file**.

## Recipe (fixed slice, wide source)

```bash
ffmpeg -y -i "$SRC" -ss START -t DUR \
  -vf "crop=$CW:$CH:$X:$Y,scale=1080:1920:flags=lanczos,format=yuv420p" \
  -c:v libx264 -crf 18 -preset medium -c:a aac -b:a 160k -movflags +faststart OUT.mp4
```

- `START` / `DUR` = original-timeline seconds (where the clip begins, its
  length). `-i` first → `t` inside crop expressions stays on the original
  timeline.
- Slice moves mid-clip → `ai_docs/timeline-hops.md`.
- Cropping ~268px wide then upscaling to 1080×1920 is a ~4× upscale →
  **soft image is expected**, don't "fix" it.

## Crop math (9:16)

A 9:16 frame is 0.5625× as wide as tall → slice width = H×9/16.

**Wide source** (H×9/16 ≤ W — the normal case):

```
CW = floor(H × 9/16), rounded down to even     e.g. 478×9/16 → 268
CH = H
X  = chosen even value in [0, W−CW]            e.g. 848×478 → range 0–580
Y  = 0
```

**Tall source** (H×9/16 > W — portrait/near-square input): crop the other way:

```
CH = floor(W × 16/9), rounded down to even
CW = W
Y  = chosen even value in [0, H−CH]
X  = 0
```

Always even dimensions and offsets (H.264 + yuv420p). If `sample_aspect_ratio`
≠ `1:1`, multiply W by it first.

**Positions** (wide source): left = `0`, center = `(W−CW)/2` rounded even,
right = `W−CW`; any other even X in range is valid — prefer an explicit X when
the user gives one.

## Encoding

libx264, crf 18, preset medium, aac 160k, `+movflags +faststart`, lanczos
scale. Override only if the request explicitly asks (e.g. smaller file →
higher CRF).

## Naming & placement

Output next to the source, named per `ai_docs/conventions.md` — short
`BASENAME_description[_N].mp4`, e.g. `hareini_cut_9x16_1.mp4`. Scratch frames
→ `/tmp/9x16_frames/`. Details: `ai_docs/conventions.md`.

## Done-criteria

- Output exists next to the source, named per conventions; source
  byte-identical (`shasum` if in doubt).
- `ffprobe`: 1080×1920, 30 fps, duration == requested, audio present.
- Position/jump checks passed per `ai_docs/verification.md` — PSNR ≈ 35–45 dB
  on sampled frames, < 15 dB means wrong geometry (rebuild).
